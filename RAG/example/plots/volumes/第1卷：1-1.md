# 第1卷：1-1

- 卷号：第1卷
- 章节范围：第1章至第1章

本卷目前围绕张飒遭遇的首次异常事件展开。故事背景指向“3132”这一未来时间节点，但具体社会环境与世界格局尚未揭示。张飒原本独自在房间内沉浸于网络游戏，对隔壁传来的闷响、哀嚎和抓挠声缺乏警惕；随着游戏中的场景与现实房间逐渐重合，电子设备失灵、墙面出现裂缝、屏幕浮现苍白扭曲的人脸，虚拟世界与现实空间之间的界限开始崩溃。

本卷当前的核心冲突，是张飒与潜伏于房间及墙壁另一侧的未知存在之间的对峙。该存在能够通过声音、游戏画面和现实空间制造影响，似乎正在逐步侵入张飒所在的房间。异常现象并非单纯来自隔壁，沉重脚步最终被确认来自房间内部，说明危险已经突破了张飒原本认知中的空间边界，并且具备隐藏、误导和逼近目标的能力。队友无法听见游戏语音中的诡异哀嚎，也暗示这一事件可能具有局部性，或异常存在能够筛选感知对象。

张飒的人物状态从最初的放松、专注游戏和忽略异样，转向被迫面对无法解释的超自然危机。他尚未表现出明确的反抗手段，也没有获得外部援助，当前成长主要体现为对异常真实性的逐步确认：从将声音视为普通杂音，到意识到游戏和现实正在发生重叠，再到发现危险已经出现在自己身后。其与队友之间暂时只有游戏中的交流，队友未能察觉异常，使张飒处于近乎孤立无援的状态。

目前已确立的关键设定包括：故事发生于3132年；某种未知力量能够干扰或改写电子设备中的游戏内容；虚拟场景可能映射现实空间，甚至成为异常入侵现实的媒介；墙壁、裂缝、声音和屏幕人脸构成了异常显现的主要渠道；异常现象可能并非所有人都能同步感知。未知存在的真实身份、来源、目的，以及它与张飒、房间或游戏之间的关系仍未揭晓。

本卷阶段性结果是，张飒已从旁观和否认状态被推入直接受威胁的封闭环境，异常存在完成了从间接制造声响到现实空间内逼近的升级，危机即将进入正面接触阶段。尚未解决的伏笔包括：墙后究竟隐藏着什么，游戏为何会出现与现实一致的场景，队友为何否认听见哀嚎，屏幕上的人脸是否属于该存在本体，以及“3132”这一时间背景是否与异常事件有关。下一阶段的悬念集中在张飒能否确认脚步声的来源、是否能够逃离房间或切断异常媒介，以及未知存在现身后将以何种方式改变现实。
